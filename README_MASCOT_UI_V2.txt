MYRIDERKU MASCOT UI V2

Pakej ini dibina daripada RIDERKB_UPLOAD.zip yang dibekalkan.

Perubahan:
- Lapisan visual baharu myriderku-mascot-v2.css untuk Customer, Rider, Vendor, Admin, Marketplace, Tracking dan Rewards.
- Palet peranan: Customer merah, Rider hijau, Vendor jingga, Admin hitam-emas.
- Ikon mascot 192px, 512px, maskable 512px dan Apple Touch Icon diganti mengikut peranan.
- Warna theme_color/background_color manifest diselaraskan.
- Tiada fail konfigurasi Firebase atau kod aliran pesanan sengaja diubah.

Cara uji:
1. Muat naik kandungan ZIP ke Netlify (drag-and-drop folder/ZIP mengikut aliran Netlify).
2. Buka setiap halaman Customer, Rider, Vendor dan Admin pada telefon.
3. Untuk melihat ikon PWA terkini, buang shortcut lama dan pasang semula selepas cache/service worker dikemas kini.

Nota: Ini kemas kini lapisan paparan dan aset ikon. Ia bukan audit keselamatan Firebase atau pengesahan operasi backend.
